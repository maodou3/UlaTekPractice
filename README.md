# UlaTekPractice

魔兽世界正式服 12.1 · 烈毒之渊 · 乌拉特克史诗 P1 搬蛋走位练习。

[下载 UlaTekPractice.zip](https://raw.githubusercontent.com/maodou3/UlaTekPractice/main/UlaTekPractice.zip)
目前版本 v0.2.0。解压后，把 `UlaTekPractice` 文件夹放入 `_retail_/Interface/AddOns/`，重启游戏并在脱战后输入 `/ulap`。

紫色圈是大怪气泡，倒计时结束时需要进圈集合。琥珀色是掉头后的蛇尾回弹波，持蛋中波会炸蛋。支持单人及 2–8 人组队，联机时所有参与者须更新到相同版本。

波次、反弹路径与坐标使用训练参数。已通过 Lua 与 8 客户端模拟测试，尚未在游戏客户端实测。
