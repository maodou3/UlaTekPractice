# UlaTekPractice

魔兽世界正式服 12.1 · 烈毒之渊 · 乌拉特克史诗 P1 搬蛋走位练习。

[下载 UlaTekPractice.zip](https://raw.githubusercontent.com/maodou3/UlaTekPractice/main/UlaTekPractice.zip)

目前版本 v0.3.0。解压后，把 `UlaTekPractice` 文件夹放入 `_retail_/Interface/AddOns/`，重启游戏并在脱战后输入 `/ulap`。支持单人及 2–8 人组队，联机时请使用相同版本。

每局从三场回放观察到的方向组合中抽取一组，两轮的主蛇尾位置与首领先出波的一侧一起变化。绿色是首领翼波，青色预警后出现的琥珀色波是幻影蛇尾独立发出的波，紫圈是大怪气泡。

波间距、轨迹和时间轴为训练参数。已通过 Lua 和 8 客户端模拟测试，尚未在游戏客户端实测。
